# Instagram Trend → WhatsApp Bot v3 (Apify)

A Dockerized Python trend-monitoring bot that uses **Apify as the primary Instagram collection layer**, Google Trends as a second signal, SQLite for historical observations, heuristic trend-velocity scoring, optional AI summarization, and WhatsApp Cloud API delivery.

## What changed in v3

- Added the official `apify-client` Python SDK.
- Added `ApifyInstagramCollector` using the maintained `apify/instagram-hashtag-scraper` Actor by default.
- Converts Apify post/reel results into normalized topic observations using hashtags, captions, likes, comments, views/plays, shares, timestamps, and post URLs when available.
- Added configurable Apify Actor ID, result limits, run wait time, maximum dataset items, and extra JSON input.
- Made Apify the primary Instagram source and disabled the old Graph API collector by default.
- Kept the Graph API adapter available as an optional secondary source.
- Improved ranking so a topic is deduplicated before the final top-N list.
- Added automated tests for the Apify adapter.

## Why Apify is used here

Apify provides a Python client that can run an Actor and then read the Actor's default dataset. The current maintained Instagram Hashtag Scraper accepts a list of hashtags and supports post/reel extraction with engagement fields. This project uses that documented Actor interface rather than browser automation, credential theft, CAPTCHA defeating, or rate-limit evasion.

## 1. Prerequisites

Install:

- Docker Desktop on Windows/macOS, or Docker Engine + Compose on Linux.
- An Apify account and API token.
- A Meta WhatsApp Cloud API setup able to send messages.
- Optionally, an AI API key for richer summaries.

## 2. Configure Apify

Copy the example environment file:

```powershell
Copy-Item .env.example .env
```

Set at minimum:

```dotenv
APIFY_API_TOKEN=apify_api_token_here
APIFY_INSTAGRAM_ACTOR=apify/instagram-hashtag-scraper
APIFY_RESULTS_LIMIT=10
APIFY_MAX_ITEMS=200
APIFY_TIMEOUT_SECONDS=210
```

The default Actor input generated by the bot is equivalent to:

```json
{
  "hashtags": ["artificialintelligence", "ai", "technology"],
  "resultsType": "posts",
  "resultsLimit": 10
}
```

The Actor treats each hashtag as a separate source, so ten hashtags with a limit of ten can return roughly up to one hundred rows before `APIFY_MAX_ITEMS` is applied.

### Optional custom Actor input

You can merge compatible fields into the Actor input using JSON:

```dotenv
APIFY_EXTRA_INPUT_JSON={"keywordSearch":true}
```

Only use fields supported by the Actor you selected.

## 3. Configure WhatsApp

Set:

```dotenv
WHATSAPP_ACCESS_TOKEN=...
WHATSAPP_PHONE_NUMBER_ID=...
WHATSAPP_RECIPIENT=919XXXXXXXXX
WHATSAPP_GRAPH_VERSION=...
```

Use the Graph API version currently supported by your Meta application/account.

## 4. Configure Gemini 3.8 Flash (optional, recommended)

Gemini is used **after crawling**: Apify collects the public Instagram data, the local scoring layer ranks the signals, and Gemini 3.8 Flash turns the resulting evidence into the WhatsApp report. Gemini itself is not the Instagram crawler.

Google currently exposes `gemini-3.8-flash` as a stable Gemini API model and documents OpenAI-compatible access through `https://generativelanguage.googleapis.com/v1beta/openai/`.

Set:

```dotenv
GEMINI_API_KEY=your_google_ai_studio_key
GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
GEMINI_MODEL=gemini-3.8-flash
```

The bot sends the collected trend evidence to Gemini through the OpenAI-compatible `/chat/completions` endpoint. No extra Python SDK is required.

You can still use the older generic AI settings as a fallback:

```dotenv
AI_API_KEY=...
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
```

If `GEMINI_API_KEY` is present, Gemini is tried first. If the Gemini request fails, the bot falls back to `AI_API_KEY`, then to the deterministic formatter.

For a first test, use Google AI Studio to create a Gemini API key and put it in `.env`; do not commit `.env` to Git.

## 5. Choose the Instagram topics to monitor

Edit `config.yaml`:

```yaml
instagram_hashtags:
  - artificialintelligence
  - ai
  - programming
  - technology
  - startups
  - machinelearning
  - generativeai
  - coding
  - tech
  - aiagents
```

These are the hashtags the Apify Actor collects from. To cover another niche, replace or extend the list.

## 6. Build

```powershell
docker compose build
```

## 7. Dry-run first

This is the safest first test because it does not send WhatsApp:

```powershell
docker compose run --rm trendbot python -m app.main --dry-run
```

You should see:

```text
Collected N raw observations
----- WHATSAPP DRY RUN -----
🔥 DAILY TREND REPORT
...
```

The first Apify run may take time depending on the Actor, input size, and your Apify plan.

## 8. Send one real report

After the dry run looks correct:

```powershell
docker compose run --rm trendbot python -m app.main --once
```

## 9. Start automatic daily operation

```powershell
docker compose up -d --build
```

Default schedule:

```text
09:00 Asia/Kolkata every day
```

To change it, edit `config.yaml`:

```yaml
schedule: "0 18 * * *"
```

Then rebuild/restart:

```powershell
docker compose up -d --build
```

## 12. Troubleshooting the Gemini connection

If the log says `Generating trend digest with Gemini model gemini-3.8-flash`, the Gemini stage is enabled. If it then reports `Gemini summarization failed`, check:

1. `GEMINI_API_KEY` is present in `.env`.
2. `GEMINI_MODEL=gemini-3.8-flash` is spelled exactly as shown.
3. The container can reach `generativelanguage.googleapis.com`.
4. The API key belongs to Google AI Studio / Gemini API and has access to the selected model.

The application will not silently lose the report: it falls back to the deterministic formatter if AI calls fail.

## 13. Stop

```powershell
docker compose down
```

## 14. Data/history

Historical observations are stored in:

```text
./data/trends.db
```

The historical database is what allows the velocity calculation to compare current observations with prior runs.

## 15. Trend scoring

Each topic gets heuristic signals for:

- recency
- frequency in the current collection
- engagement
- source signal
- historical velocity

The bot then deduplicates topics and sends the top-scoring items.

These are project-specific heuristics, not official Instagram rankings.

## 16. Important operational notes

### Apify cost

Apify Actors can consume platform resources and may incur charges depending on the Actor, result volume, and your plan. Keep `APIFY_RESULTS_LIMIT`, number of hashtags, and schedule frequency reasonable.

### Instagram coverage

The system monitors the Instagram topics you put in `instagram_hashtags`. It is therefore a **configured trend monitor**, not a claim that it has access to Instagram's entire internal global trending algorithm.

### Security

Never put API tokens directly into `config.yaml`, source code, or Git. Keep them in `.env` and keep `.env` out of version control.
